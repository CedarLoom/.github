# Security policy

This policy applies to every CedarLoom repository without a `SECURITY.md` of its own.

## Supported versions

Fixes go into the latest release of each project.

## Reporting a vulnerability

Report it privately, not as a public issue: open the repository's Security tab and choose "Report a vulnerability" (GitHub private vulnerability reporting). Include the affected version, the component and the steps to reproduce. The fix and the advisory are published together.
